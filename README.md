# homebrew-tap

Homebrew tap for [fwdctl](https://github.com/forwardnetworks/fwdctl), the Forward Networks CLI.

```bash
brew install forwardnetworks/tap/fwdctl
brew upgrade fwdctl
```

The formula installs the prebuilt release binaries (macOS arm64 and Intel, Linux amd64) and is updated by each fwdctl release.
